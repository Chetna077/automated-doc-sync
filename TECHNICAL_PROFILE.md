# automated-doc-sync — Technical Profile

## 1. Executive Summary

- **Application Name:** automated-doc-sync
- **Description:** A small CLI that keeps a repository's technical profile documentation in sync with its actual code. Point it at a repo and a template, and it fills in every placeholder it can verify from the code — and marks anything it can't verify as `Not Found` rather than guessing.
